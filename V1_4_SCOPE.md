# V1.4 scope interpretation

The attached requirement is titled **“FIELDNOTES TRAVEL PLANNER — V1.3 UPGRADE / OPTION A”** and proposes four changes relative to V1.2. The user's direct instruction **“This is V1.4”** overrides that old version label.

Accordingly, this implementation upgrades the **existing V1.3 Option B** application to **V1.4**. The first three proposed changes (activity colour override, single-click Select Mode, timetable PNG/PDF/Print) already exist in the V1.3 base and are carried forward rather than reimplemented. The fourth change, **Google Maps Embed API**, is the new V1.4 feature.

The original interactive editable map remains the editing mode, and Google Maps is added as an optional iframe viewer. This follows the requirement to preserve custom markers, map area selection and saved real geographic coordinates.
